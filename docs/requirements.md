# 요구사항 및 구현 범위

원문: `planning/prmopt_202610127_02.md`. 이 문서는 그 요구사항을 MVP 범위로 정리한 것이다.

## 사용자와 핵심 흐름

| 사용자 | 흐름 |
|---|---|
| 비로그인 방문자 | 홈 → 검색/탐색 → 공개 글 읽기 (쓰기 동작 시 로그인 안내) |
| 작성자 | 로그인 → 파일 업로드 → 제목·태그·공개범위 입력 → 미리보기/검토 → 게시 → 수정/삭제 → 받은 피드백·알림 확인 |
| 독자 | 글 읽기 → 감상 작성 → 문장 선택 후 하이라이트 저장 → 내 하이라이트에서 다시 보기 |
| 관리자 | 계정 발급 → 사용자 정지/권한 변경 → 글 숨김/삭제, 댓글 삭제 → 신고 처리 |

## 정책 (가정)

- 하이라이트 중복: 같은 사용자·같은 글·같은 구간(시작/끝)은 한 번만 저장. 겹치는 다른 구간은 허용.
- 하이라이트 목록: 지금도 읽을 수 있는 글의 하이라이트만 표시 (작성자가 비공개 전환/관리자 숨김 시 숨기고 개수만 안내).
- 인기 글: 댓글(감상) 수, 동점이면 최신순. 댓글이 없는 글은 홈 인기 섹션에서 제외.
- 비공개 글: 작성자 본인만 열람. 관리자도 본문 열람 불가(관리 목록에서 메타데이터만 확인, 숨김/삭제 가능).
- 관리자 숨김(hidden) 글: 작성자만 열람 가능하며 댓글/하이라이트 불가.
- 알림: 본인 활동은 알리지 않음. 이메일/푸시는 보내지 않음.
