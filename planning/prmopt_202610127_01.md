역할 부여 (Role)
너는 10년 차 이상의 풀스택 웹 개발자이자 프로덕트 디자이너(UI/UX 전문가)야. 내 아이디어를 바탕으로 완성도 높은 웹 페이지 플랫폼의 기획부터 핵심 코드 구조까지 설계해 줘.

프로젝트 개요 (Overview)
- 플랫폼 이름: 에세이 글쓰기
- 핵심 목적: 사용자가 작성한 글 파일을 업로드 하고 다른 사용자와 공유하며, 사용자들이 글에 피드백, 소감 등을 남길 수 있는 웹 플랫폼
- 타겟 사용자: 에세이 글쓰기에 관심 있는 사용자
- 주요 기능 (Core Features):
  1. 회원 등록: 회원가입은 받지 않음.
  2. 회원 관리
  3. 글 업로드 기능 및 검색/필터링 기능
    - 파일 업로드: 사용자가 글 파일을 업로드할 수 있음.
        - 파일 형식: 워드, markdown
    - 검색/필터링: 사용자가 업로드된 글을 제목, 작성자, 태그 등으로 검색하고 필터링할 수 있음.
  4. 피드백 기능: 
    - 글에 이모지 남길 수 있음
    - 사용자가 다른 사용자의 글에 피드백이나 소감을 남길 수 있음.
  5. 사용자가 좋다고 생각하는 문장을 하이라이트하고 저장할 수 있음.
  


요청 사항 (Deliverables)
1. 서비스 구조 및 페이지 목록 (Sitemap)
    - 사용자가 접속해서 거치게 될 주요 페이지(홈, 상세, 마이페이지 등)의 구조를 정리해 줘.
    - 예)
        - 홈 페이지: 최신 글 목록, 인기 글, 검색 바
        - 글 업로드 페이지: 파일 업로드, 제목, 태그 입력
        - 글 상세 페이지: 글 내용, 피드백, 하이라이트 기능
        - 마이페이지: 사용자가 업로드한 글, 하이라이트한 문장, 피드백 관리
        - 회원 관리 페이지: 회원 정보 확인 및 수정, 회원 탈퇴 기능
        - 피드백 관리 페이지: 사용자가 받은 피드백 확인 및 관리
        - 하이라이트 관리 페이지: 사용자가 하이라이트한 문장 확인 및 관리
        - 글 검색/필터링 페이지: 제목, 작성자, 태그 등으로 글 검색 및 필터링
        - 알림 페이지: 사용자가 받은 알림 확인 및 관리
        - 설정 페이지: 계정 설정, 알림 설정, 개인정보 관리
2. 데이터베이스 설계 (ERD / 테이블 구조)
	• 유저(Users), 게시글(Posts), 댓글(Comments) 등 핵심 데이터 테이블의 컬럼과 관계를 정의해 줘.
3. 핵심 UI/UX 레이아웃 설계
	• 메인 페이지의 화면 구성(Hero 섹션, 네비게이션바, 콘텐츠 카드 등)을 마크다운이나 텍스트 와이어프레임으로 그려줘.
4. 초기 프로토타입 코드 (MVP)
	• 위 기능을 동작하게 만드는 핵심 [HTML/Tailwind/React 등] 단일 파일 또는 초기 코드 스켈레톤(Skeleton)을 작성해 줘.
5. 단계별 개발 로드맵
	• 1단계(UI 프로토타입) -> 2단계(기능 연동) -> 3단계(배포) 순으로 내가 무엇부터 코딩해야 하는지 순서를 알려줘.
